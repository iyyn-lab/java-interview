# 3. What is Spring Boot?

Spring Boot is built on top of the Spring Framework.

It makes it easier to create and run Spring applications with less configuration.

Simple definition:

> **Spring Boot is a Java framework used to build production-ready backend applications and REST APIs quickly using the Spring Framework.**

# 5. What is a Bean?

A **Bean** is an object that is created and managed by the Spring container.

For example:

```java
@Service
public class ProductService {
}
```

Spring creates and manages the `ProductService` object.

Conceptually:

```text
Spring Container

ProductController Bean
ProductService Bean
ProductRepository Bean
UserService Bean
```

Spring manages these objects and their relationships.

# 6. Dependency Injection

Dependency Injection is one of the most important Spring concepts.

## What is a Dependency?

Suppose `ProductController` needs `ProductService`.

Suppose:

```text
ProductController
       ↓
needs
       ↓
ProductService
```

`ProductService` is a dependency of `ProductController`.

Without DI, the Controller could create the Service itself:

```java
ProductService service = new ProductService();
```

With Spring, Spring creates and provides the required object.

```java
@RestController
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }
}
```

Spring automatically provides `ProductService`.

Spring sees that `ProductController` needs `ProductService` and injects it.

```text
Spring Container
      ↓
Creates ProductService
      ↓
Injects it into ProductController
```

### Simple definition

> Dependency Injection means that an object's required dependencies are provided to it instead of the object creating them itself.

# 10. Spring Boot vs Spring



### Spring

Spring is the main framework.

It provides features like:

```text
Dependency Injection
Web
Security
Database
Transactions
```



### Spring Boot

Spring Boot makes Spring development easier.

It provides:

```text
Auto Configuration
Embedded Server
Starter Dependencies
Production-ready features
Less manual configuration
```

Simple comparison:

```text
Spring
  ↓
Powerful but requires more configuration

Spring Boot
  ↓
Spring + easier setup + auto configuration
```

# 11. Important Interview Points



### What is Spring Boot?

> Spring Boot is a Java-based framework built on top of Spring that simplifies the development of production-ready applications and REST APIs.



### What is Dependency Injection?

> Dependency Injection is a mechanism where Spring provides the required dependencies to an object instead of the object creating them itself.



### What is a Bean?

> A Bean is an object that is created and managed by the Spring container.



### What does Controller do?

> Controller handles HTTP requests and sends responses.



### What does Service do?

> Service contains business logic.



### What does Repository do?

> Repository handles database-related operations.



### What is Spring Container?

> Spring Container manages Spring Beans and their dependencies.
