# Spring Boot Annotations

Spring Boot uses annotations to tell Spring how classes, methods, and objects should be managed.

Annotations start with `@`.

Example:

```java
@Service
public class ProductService {
}
```

Here `@Service` tells Spring that `ProductService` is a service component.

---

# 1. @Controller

`@Controller` is used to create a Controller class.

The Controller receives HTTP requests from the client.

### Example

```java
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class ProductController {

    @GetMapping("/products")
    public String getProducts() {
        return "products";
    }
}
```



### What does it do?

```text
Client
  ↓
GET /products
  ↓
ProductController
  ↓
Response
```

`@Controller` is commonly used when working with Spring MVC and returning views/pages.

### Remember

> `@Controller` → Handles web requests and can return a view.

---



# 2. @RestController

`@RestController` is commonly used for REST APIs.

It allows the Controller to return data directly as the HTTP response.

### Example

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @GetMapping("/products")
    public String getProducts() {
        return "Product List";
    }
}
```

Request:

```text
GET /products
```

Response:

```text
Product List
```

For a REST API, the response can also be an object.

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @GetMapping("/product")
    public Product getProduct() {
        return new Product(1, "Apple");
    }
}
```



### What does it do?

`@RestController` is effectively:

```text
@Controller
+
@ResponseBody
```

So the return value is written directly to the HTTP response.

### Remember

> `@RestController` → Used for REST APIs.

---



# 3. @Service

`@Service` is used for the Service layer.

The Service layer contains the application's business logic.

### Example

```java
import org.springframework.stereotype.Service;

@Service
public class ProductService {

    public String getProduct() {
        return "Apple";
    }
}
```

The Controller can use the Service:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }

    @GetMapping("/product")
    public String getProduct() {
        return productService.getProduct();
    }
}
```



### Flow

```text
Client
  ↓
Controller
  ↓
Service
  ↓
Business Logic
```

Business logic could be:

```text
Check stock
Calculate price
Calculate discount
Validate product
```



### Remember

> `@Service` → Contains business logic.

---



# 4. @Repository

`@Repository` is used for the Repository/Data Access layer.

It is responsible for communicating with the database.

### Example

```java
import org.springframework.stereotype.Repository;

@Repository
public class ProductRepository {

    public String findProduct() {
        return "Apple";
    }
}
```

The Service can use the Repository:

```java
import org.springframework.stereotype.Service;

@Service
public class ProductService {

    private final ProductRepository productRepository;

    public ProductService(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }

    public String getProduct() {
        return productRepository.findProduct();
    }
}
```



### Flow

```text
Service
   ↓
Repository
   ↓
Database
```

In real applications, repositories are often created using Spring Data JPA interfaces.

Example:

```java
import org.springframework.data.jpa.repository.JpaRepository;

public interface ProductRepository
        extends JpaRepository<Product, Long> {
}
```

Spring Data provides common database operations such as:

```text
find
save
update
delete
```



### Remember

> `@Repository` → Used for database/data access operations.

---



# 5. @Autowired

`@Autowired` is used for Dependency Injection.

It tells Spring to provide the required dependency.

### Example

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class ProductService {

    private final ProductRepository productRepository;

    @Autowired
    public ProductService(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }
}
```

Spring finds the `ProductRepository` Bean and provides it to `ProductService`.

### Flow

```text
Spring Container
      ↓
ProductRepository Bean
      ↓
Inject
      ↓
ProductService
```



### Constructor Injection

If a class has a single constructor, modern Spring can automatically use it without `@Autowired`.

```java
import org.springframework.stereotype.Service;

@Service
public class ProductService {

    private final ProductRepository productRepository;

    public ProductService(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }
}
```

This is called **Constructor Injection**.

### Remember

> `@Autowired` → Used to inject dependencies managed by Spring.

---



# 6. @Bean

`@Bean` is used to tell Spring to create and manage an object as a Spring Bean.

It is normally used inside a `@Configuration` class.

### Example

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AppConfig {

    @Bean
    public ProductService productService() {
        return new ProductService();
    }
}
```

Here:

```text
@Bean
  ↓
ProductService object
  ↓
Managed by Spring
```

The important difference is:

```text
@Service
    ↓
Spring automatically detects the class

@Bean
    ↓
Developer explicitly tells Spring
which object should be managed
```



### When is @Bean useful?

It is useful when we need to manually configure or create an object.

For example:

```text
Third-party library object
Custom configuration
Special application object
```



### Remember

> `@Bean` → Creates a Spring-managed Bean from a method.

---



# 7. @Configuration

`@Configuration` marks a class as a configuration class.

It is commonly used with `@Bean`.

### Example

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AppConfig {

    @Bean
    public ProductService productService() {
        return new ProductService();
    }
}
```

Here:

```text
@Configuration
       ↓
     @Bean
       ↓
ProductService Bean
       ↓
Managed by Spring
```



### What does it do?

It tells Spring:

> "This class contains configuration information for the application."



### Remember

> `@Configuration` → Defines configuration for Spring Beans and application setup.

---



# 8. @GetMapping

`@GetMapping` maps an HTTP GET request to a method.

### Example

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @GetMapping("/products")
    public String getProducts() {
        return "Product List";
    }
}
```

Request:

```text
GET /products
```

calls:

```java
getProducts()
```



### Remember

> `@GetMapping` → Handles HTTP GET requests.

---



# 9. @PostMapping

`@PostMapping` maps an HTTP POST request to a method.

It is commonly used when creating data.

### Example

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RestController;
```

@RestController
public class ProductController {

```
@PostMapping("/products")
public String createProduct() {
    return "Product Created";
}
```

}

```

Request:

```text
POST /products
```

### Remember

> `@PostMapping` → Handles HTTP POST requests.

---

# 10. @PutMapping

`@PutMapping` is commonly used for updating existing data.

### Example

```java
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @PutMapping("/products/10")
    public String updateProduct() {
        return "Product Updated";
    }
}
```

### Remember

> `@PutMapping` → Handles HTTP PUT requests.

---

# 11. @DeleteMapping

`@DeleteMapping` is commonly used for deleting data.

### Example

```java
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @DeleteMapping("/products/10")
    public String deleteProduct() {
        return "Product Deleted";
    }
}
```

### Remember

> `@DeleteMapping` → Handles HTTP DELETE requests.

---

# 12. @RequestBody

`@RequestBody` is used to read data sent in the HTTP request body.

Example request:

```json
{
  "name": "Apple",
  "price": 100
}
```

Java example:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @PostMapping("/products")
    public String createProduct(@RequestBody Product product) {
        return "Product Created";
    }
}
```

### Remember

> `@RequestBody` → Converts request body data into a Java object.

---

# 13. @PathVariable

`@PathVariable` gets a value from the URL path.

Example:

```text
GET /products/10
```

Here `10` is the product ID.

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @GetMapping("/products/{id}")
    public String getProduct(@PathVariable Long id) {
        return "Product ID: " + id;
    }
}
```

Result:

```text
Product ID: 10
```

### Remember

> `@PathVariable` → Gets a value from the URL path.

---

# 14. @RequestParam

`@RequestParam` gets a value from a query parameter.

Example:

```text
GET /products?category=fruits
```

Java example:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ProductController {

    @GetMapping("/products")
    public String getProducts(
            @RequestParam String category) {

        return "Category: " + category;
    }
}
```

Result:

```text
Category: fruits
```

### Remember

> `@RequestParam` → Gets a value from the query string.

---

# 15. @ResponseStatus

`@ResponseStatus` can be used to specify the HTTP status code returned by an endpoint or exception handler.

Example:

```java
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestController;

@ResponseStatus(HttpStatus.NOT_FOUND)
public class ProductNotFoundException extends RuntimeException {

    public ProductNotFoundException(String message) {
        super(message);
    }
}
```

If this exception is thrown:

```text
ProductNotFoundException
        ↓
HTTP 404 NOT FOUND
```

### Remember

> `@ResponseStatus` → Specifies an HTTP response status.

# 16. Annotation Summary


| Annotation        | Purpose                       |
| ----------------- | ----------------------------- |
| `@Controller`     | Handles web requests          |
| `@RestController` | Handles REST APIs             |
| `@Service`        | Business logic                |
| `@Repository`     | Database/data access          |
| `@Autowired`      | Dependency Injection          |
| `@Bean`           | Creates a Spring-managed Bean |
| `@Configuration`  | Defines configuration         |
| `@GetMapping`     | Handles GET requests          |
| `@PostMapping`    | Handles POST requests         |
| `@PutMapping`     | Handles PUT requests          |
| `@DeleteMapping`  | Handles DELETE requests       |
| `@RequestBody`    | Reads request body            |
| `@PathVariable`   | Reads value from URL path     |
| `@RequestParam`   | Reads query parameter         |
| `@ResponseStatus` | Sets HTTP response status     |

# 17. Most Important Annotations for Interview

Start by understanding these first:

```text
@Controller
@RestController
@Service
@Repository
@Autowired
@Bean
@Configuration
```

Then learn the API-related annotations:

```text
@GetMapping
@PostMapping
@PutMapping
@DeleteMapping
@RequestBody
@PathVariable
@RequestParam
```

And later:

```text
@ExceptionHandler
@ControllerAdvice
@RestControllerAdvice
```

# 18. Simple Architecture With Annotations

```text
                    Client
                      ↓
              @RestController
                      ↓
                  @Service
                      ↓
                @Repository
                      ↓
                   Database


Spring Container
       ↓
     Beans
       ↓
Dependency Injection
       ↓
    @Autowired
```

### Easy way to remember

```text
@Controller
     ↓
Request handling

@Service
     ↓
Business logic

@Repository
     ↓
Database access

@Autowired
     ↓
Dependency Injection

@Bean
     ↓
Create/manage an object

@Configuration
     ↓
Application configuration
```

> **Don't try to memorize every annotation at once. First understand what each annotation is responsible for and where it belongs in the application architecture.**
